MODULES

Build by module, not by boilerplate.

Every capability is a self-contained module that owns its files and migrations and declares how it works with the others. Three complete compositions are verified golden paths for the closed beta. Other packs are labeled composition checked or external verification required.

COMPOSED, NOT CLONED

Only what you pick.

You are not forking a template and deleting the parts you do not need. The repo is composed from the modules you choose, so there is no dead code to read past, and it is yours to keep.

  • No dead code. Files and migrations come only from the modules you installed.
  • Conflict-checked. Modules declare how they fit, so picks that clash are caught before generation.
  • Broad output rights. Own project-specific code and keep perpetual commercial rights to generated ProdPack code, subject to third-party licenses.
