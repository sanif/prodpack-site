Security-first by default

Security is the first feature, not a cleanup task.

ProdPack validates the selected composition before it writes, wires explicit authorization guards, and requires production secrets instead of silently shipping public defaults.

SECRETS AND TOKENS

Unique in development. Required in production.

JWT projects receive a unique 64-byte development key, so generated repositories never share a public fallback. In production, authentication fails closed until the operator supplies JWT_SECRET.

Environment examples and the success checklist name every production value you still need to provide, with hints for where each value comes from.

WHAT SHIPS GUARDED

The defenses a senior team would set up, already wired.

The core baseline ships automatically. Optional defenses appear when you select their modules, and the review shows exactly which controls are present.

  • Optional rate limitingSelect the rate-limiting module to throttle abuse and brute-force attempts per IP and per user.
  • Optional Cloudflare TurnstileSelect Turnstile to protect signup from automated registrations without adding a puzzle.
  • Security headers and strict CORS on by defaultSane defaults for headers and a tight cross-origin policy, configured out of the box.
  • Admin routes guarded for superusers onlyPrivileged endpoints check for a superuser, so admin tooling is never one missing guard away from exposure.
  • Password-provider hashingWhen password auth is selected, credentials use a slow, salted bcrypt hash and are never stored in plain text.
  • Structured logging on every webhook and jobWebhooks and background jobs emit structured events you can trace, alert on, and audit.
